# 📊 Product Sales Data Analysis – Power BI Dashboard

An interactive Power BI dashboard that analyzes product sales performance across segments, countries and time, to help answer: **what sells, where, to whom, and how profitably?**

## 📌 Project Overview
This project turns raw sales data into a one-page business dashboard. It tracks key performance indicators (KPIs) and lets users filter the results by product, segment, country and year.

## 🗂️ Dataset
- **Source:** Financial Sample dataset (Excel, `Financial Sample.xlsx`)
- **Size:** 700 rows × 16 columns *(update if your count differs)*
- **Period:** 2013 – 2014
- **Key columns:** Segment, Country, Product, Discount Band, Units Sold, Manufacturing Price, Sale Price, Gross Sales, Discounts, Sales, COGS, Profit, Date

| Dimension | Values |
|---|---|
| Segments | Government, Midmarket, Channel Partners, Enterprise, Small Business |
| Countries | Canada, France, Germany, Mexico, United States of America |
| Products | Carretera, Montana, Paseo, Velo, VTT, Amarilla |

## 🎯 Objectives
- Measure overall sales, profit and units sold
- Identify the best and worst performing products, segments and countries
- Understand the impact of discounts on profitability
- Track sales and profit trends over time

## 📈 Dashboard Features
- **KPI cards:** Total Sales, Total Profit, Total Units Sold, Profit Margin, Average Discount
- **Line chart:** Sales and profit trend over time
- **Column charts:** Sales, profit and units by product, and by country and segment
- **Map:** Geographic view of sales and profit by country
- **Treemap:** Segment contribution to sales and profit
- **Slicers:** Filter by Product, Year, Segment and Country
- **Navigation buttons and bookmarks** for an easy user experience

## 🛠️ Tools & Skills Used
- **Power BI Desktop** – data modeling and visualization
- **DAX** – calculated measures (Total Sales, Total Profit, Profit Margin, Average Discount)
- **Power Query** – data cleaning and transformation
- **Microsoft Excel** – source data

## ▶️ How to Use
1. Clone or download this repository
2. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only)
3. Open `Product_Sales_Data_Analysis_Project.pbix`
4. If prompted, update the data source path to the downloaded `Financial Sample.xlsx` (Home → Transform data → Data source settings)
